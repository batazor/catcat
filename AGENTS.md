# ideal-saturday — памятка для агента

## Обновления после ревью

- Анимации колоды и перехода между строкой плана и карточкой — `src/js/ui/motion.js`: выбор собирает стопку, отказ уводит карту вниз, уход колоды синхронизирован с лапой. Постоянное «дыхание» карты убрано. Временные слои очищаются при завершении, изменении размера окна и включении reduced motion.

- Свайп влево отменяет выбранную карту и сбрасывает выбор в расписании.
- Enter на навигации отключён. Во время анимации лапы повторные действия игнорируются.
- Черновик (окно времени, выборы, экран редактирования) хранится в localStorage через `src/js/draft.js`. Квитанция отправки также в localStorage. Галочка оферты после перезагрузки сброшена.
- В итоговом плане есть рукописные ссылки «Изменить» для занятий, направления и времени.
- Загрузка SVG ограничена 10 секундами. Сбой сцены или лапы не блокирует план; при сбое кота есть видимая кнопка повторной загрузки.
- Пользователь оставил расчёт времени приблизительным: небольшое отклонение допустимо.
- Превью ссылки: `src/images/saturday-preview.png`, Open Graph и Twitter Card.

Одноразовый личный проект: страница «собери свою субботу в Чангу», которую пользователь (Batazor) отправит одному человеку (девушке, обращение в UI — на «ты», женский род: «свободна», «Уверена?»). Не сервис, не продукт. Статика без сборщика: `index.html` + `src/`. Хостинг — GitHub Pages через `.github/workflows/deploy.yml`: только деплой статики при push в `main` или ручном запуске. README, тесты, package.json — не нужны.

Язык общения с пользователем — русский, терсе, без воды. Каждый факт о местах/часах/дороге — только с источником; непроверенное помечать «не проверено».

## Что уже сделано (v27 артефакта → этот код)

Поток: интро (камера спускается с неба к пляжу, 3 слоя параллакса, спящий кот на песке) → стартовый экран собирается по очереди → слайдер «от → до» (дефолт 14:00–18:00) → шаги-карточки → итоговый план с кнопкой «Отправить план».

Отправка: Supabase `uuvaoycofcvdtzfixhlf`, таблица `public.saturday_plans`. Только запись из страницы через publishable key; чтение, изменение и удаление браузеру не разрешены. Без авторизации и дополнительных экранов. Нужна галочка оферты. При успехе «Отправлено ♥»; при ошибке можно повторить с тем же UUID без дубля. SQL — в `supabase/migrations/`, публичные настройки — `src/js/supabase-config.js`. Секретные ключи в статику не добавлять. При отправке `client_info` сохраняет подсказки браузера: устройство, браузер, язык, размер окна, user-agent и признак автоматизации. Это не проверка личности и не надёжный детектор ботов. Метаданные не входят в ключ повторной отправки плана.

Правила времени (`src/js/schedule.js`, `steps.js`, `facts.js`):
- < 2 ч — «Так не играем», кнопка заблокирована.
- 2–3 ч — один шаг `short`: настолки или руфтоп (руфтоп только если окно захватывает закат), днём настолки/бильярд.
- < 4 ч — кнопка «Дальше» дважды переспрашивает: «Уверена?» → «Точно-точно?».
- ≥ 4 ч — шаг «Куда?»: Чангу (настолки/бильярд/оригами → птицы/ботсад → закат на пляже/руфтопе) или Букит (Гунунг-Паюнг/Меласти → кечак в Улувату/закат на пляже).
- Невлезающая карта: перечёркнута, «Было бы круто, но нам не хватит времени. <причина>», кнопка становится «Пропустить», кот плачет. Кот в пузыре предлагает сдвинуть окно («Останемся до 19:00?», «Начнём с 12:00?») — тап по пузырю раздвигает окно и пересчитывает прошлые шаги.
- Закат 18:16, слот 17:30–19:30. Парк птиц 9:00–17:30 (+1 ч дороги). Ботсад Бедугул сб–вс 8:00–17:00 (+2 ч дороги, стоимость карты 4 ч). Кечак 18:00–19:00, быть к 16:30. Дорога Чангу → Букит зависит от часа выезда (`time.js: travel`). Обратная дорога нигде не считается. Источники — в `facts.js`.

UI-решения, которые пользователь выбирал осознанно — не менять без спроса:
- Тёплая палитра (песок/крем/коричневый), «стикерный» стиль: коричневые контуры 2–2.5px, жёсткая тень, кнопки проседают при нажатии. Никакого белого, никаких бирюзовых/серых.
- Карты — веер игральных карт с угловыми номерами «1/2», свайп вправо = ДА, влево = НЕТ, тап = выбор; описание закрыто стираемой «фольгой» (canvas); фон карт — тёплый градиент + текстура «карта с дорогами» (Google Maps нельзя: без ключа и внешних картинок не было в артефакте; теперь в статике можно, если пользователь попросит).
- Кот: рыжий, контурный, круглые щёки, глаза открываются плавно (не «испуганно»), хвост сужающийся с полосками. Реагирует на тап (мяу/мрр/мур-мур/♥/ещё!, без «ну?»). Курсор над котом — лапка.
- Лапа при «Дальше»: выходит со случайной стороны, рука длинная (всегда за край экрана), без отскока, нажимает и утаскивает кнопку; лапа и кнопка на одной keyframe-таймлинии 1,3 с.
- Прогресс-бар убран. Угловые иконки карт убраны (осталась большая иконка в капле).
- Тексты переписаны по гайдам «как убрать ИИ-звучание»: без тире-дроблений, без «не X, а Y», без обещаний от первого лица. Фразы пользователя сохранены дословно: «Так не играем», «Уверена?», «Точно-точно?», «Было бы круто, но нам не хватит времени».
- Анимации мягкие, мультяшные, без резкого; всё уважает `prefers-reduced-motion`.

## Структура

```
index.html                 каркас, <template id="tpl-step"> и <template id="tpl-card">
src/styles/                порядок подключения: tokens, base, cards, slider, buttons, summary, cat, paw, intro
src/js/facts.js            цифры + ссылки
src/js/time.js             clock / fmtDur / travel
src/js/steps.js            конфиг шагов: when (ветвление), check (причина), cost, fixedAt, acc (аксессуар кота)
src/js/schedule.js         движок без DOM: createSchedule → state, pick, needWindow, computeRoute, rows, planText
src/js/ui/cards.js         buildStep, fan, drag (свайп), glow, фольга
src/js/ui/cat.js           mountCat, setCat(mood/acc), pokeCat, catOffer
src/js/ui/paw.js           pawTap(btn, cb)
src/js/ui/intro.js         runIntro(sceneSvg)
src/js/ui/effects.js       bubbles, parallax
src/js/ui/summary.js       renderPlan, wireSubmit
src/js/submission.js       сбор выбранного плана и POST в Supabase
src/js/main.js             склейка; SVG грузятся fetch'ем из src/svg (или из window.__ASSETS, если когда-то снова соберём один файл)
src/svg/                   cat.svg (якоря аксессуаров завязаны на координаты головы 60,46), paw.svg, scene.svg
```

Запуск локально: любой статический сервер из корня (`python3 -m http.server`), `file://` не подходит из-за ES-модулей. Проверено в headless Chrome полным сценарием 14→18 → сад → «с 11:00» → закат → «до 19:00» → план.
